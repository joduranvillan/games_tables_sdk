# Backgammon (`backgammon_game`)

## Overview
Deterministic rule engine implementation for **Backgammon** built on `open_table_core` and `open_table_engine`.

## Key Features
- **Crate**: `backgammon_game`
- **Godot Scene**: `res://backgammon_board.tscn` / `res://scenes/backgammon_board.gd`
- **Deterministic Replay**: Full command/event stream support and state hash verification.
- **Multiplayer & AI**: Supports Local Hotseat, vs AI, LAN TCP, Native P2P, and WebSocket Relay.
