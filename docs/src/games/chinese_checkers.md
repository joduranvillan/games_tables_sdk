# Chinese Checkers (`chinese_checkers_game`)

## Overview
Deterministic rule engine implementation for **Chinese Checkers** built on `open_table_core` and `open_table_engine`.

## Key Features
- **Crate**: `chinese_checkers_game`
- **Godot Scene**: `res://chinese_checkers_board.tscn` / `res://scenes/chinese_checkers_board.gd`
- **Deterministic Replay**: Full command/event stream support and state hash verification.
- **Multiplayer & AI**: Supports Local Hotseat, vs AI, LAN TCP, Native P2P, and WebSocket Relay.
