# Monopoly (`monopoly_game`)

## Overview
Deterministic rule engine implementation for **Monopoly** built on `open_table_core` and `open_table_engine`.

## Key Features
- **Crate**: `monopoly_game`
- **Godot Scene**: `res://monopoly_board.tscn` / `res://scenes/monopoly_board.gd`
- **Deterministic Replay**: Full command/event stream support and state hash verification.
- **Multiplayer & AI**: Supports Local Hotseat, vs AI, LAN TCP, Native P2P, and WebSocket Relay.
