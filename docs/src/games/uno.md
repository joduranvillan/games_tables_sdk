# Uno (`uno_game`)

## Overview
Deterministic rule engine implementation for **Uno** built on `open_table_core` and `open_table_engine`.

## Key Features
- **Crate**: `uno_game`
- **Godot Scene**: `res://uno_board.tscn` / `res://scenes/uno_board.gd`
- **Deterministic Replay**: Full command/event stream support and state hash verification.
- **Multiplayer & AI**: Supports Local Hotseat, vs AI, LAN TCP, Native P2P, and WebSocket Relay.
