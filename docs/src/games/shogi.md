# Shogi (`shogi_game`)

## Overview
Deterministic rule engine implementation for **Shogi** built on `open_table_core` and `open_table_engine`.

## Key Features
- **Crate**: `shogi_game`
- **Godot Scene**: `res://shogi_board.tscn` / `res://scenes/shogi_board.gd`
- **Deterministic Replay**: Full command/event stream support and state hash verification.
- **Multiplayer & AI**: Supports Local Hotseat, vs AI, LAN TCP, Native P2P, and WebSocket Relay.
