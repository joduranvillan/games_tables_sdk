# Mille Bornes (`mille_bornes_game`)

## Overview
Deterministic rule engine implementation for **Mille Bornes** built on `open_table_core` and `open_table_engine`.

## Key Features
- **Crate**: `mille_bornes_game`
- **Godot Scene**: `res://mille_bornes_board.tscn` / `res://scenes/mille_bornes_board.gd`
- **Deterministic Replay**: Full command/event stream support and state hash verification.
- **Multiplayer & AI**: Supports Local Hotseat, vs AI, LAN TCP, Native P2P, and WebSocket Relay.
