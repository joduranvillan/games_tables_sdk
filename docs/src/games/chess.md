# Chess (`chess_game`)

## Overview
Deterministic rule engine implementation for **Chess** built on `open_table_core` and `open_table_engine`.

## Key Features
- **Crate**: `chess_game`
- **Godot Scene**: `res://chess_board.tscn` / `res://scenes/chess_board.gd`
- **Deterministic Replay**: Full command/event stream support and state hash verification.
- **Multiplayer & AI**: Supports Local Hotseat, vs AI, LAN TCP, Native P2P, and WebSocket Relay.
