# Battleship (`battleship_game`)

## Overview
Deterministic rule engine implementation for **Battleship** built on `open_table_core` and `open_table_engine`.

## Key Features
- **Crate**: `battleship_game`
- **Godot Scene**: `res://battleship_board.tscn` / `res://scenes/battleship_board.gd`
- **Deterministic Replay**: Full command/event stream support and state hash verification.
- **Multiplayer & AI**: Supports Local Hotseat, vs AI, LAN TCP, Native P2P, and WebSocket Relay.
