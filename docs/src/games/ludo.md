# Ludo (`ludo_game`)

## Overview
Deterministic rule engine implementation for **Ludo** built on `open_table_core` and `open_table_engine`.

## Key Features
- **Crate**: `ludo_game`
- **Godot Scene**: `res://ludo_board.tscn` / `res://scenes/ludo_board.gd`
- **Deterministic Replay**: Full command/event stream support and state hash verification.
- **Multiplayer & AI**: Supports Local Hotseat, vs AI, LAN TCP, Native P2P, and WebSocket Relay.
