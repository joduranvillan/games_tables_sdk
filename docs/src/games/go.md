# Go (`go_game`)

## Overview
Deterministic rule engine implementation for **Go** built on `open_table_core` and `open_table_engine`.

## Key Features
- **Crate**: `go_game`
- **Godot Scene**: `res://go_board.tscn` / `res://scenes/go_board.gd`
- **Deterministic Replay**: Full command/event stream support and state hash verification.
- **Multiplayer & AI**: Supports Local Hotseat, vs AI, LAN TCP, Native P2P, and WebSocket Relay.
