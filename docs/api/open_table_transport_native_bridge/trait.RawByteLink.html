Expand description

Lo mínimo que un plugin nativo (Nearby Connections en Android, MultipeerConnectivity en iOS) tiene que poder hacer, visto desde Rust. A propósito NO sabe nada de PlayerId, Command, ni handshake — eso vive en NativeHostTransport/NativeClientTransport, que envuelven cualquier RawByteLink sin importar qué hay debajo.

peer_tag es el identificador que da la plataforma nativa: el endpointId de Nearby Connections, o el displayName/hash de un MCPeerID de MultipeerConnectivity. Es un string opaco — este crate nunca intenta interpretarlo.
