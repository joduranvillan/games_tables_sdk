§open_table_engine

Motor de reglas y orquestación de partidas para OpenTable Engine.

Construido sobre bevy_ecs y los contratos de open_table_core. Proporciona la estructura Session, RuleEngine, control de turnos, gestión de eventos con filtrado por visibilidad, timeouts de reconexión y soporte para simulación de partidas deterministas.
