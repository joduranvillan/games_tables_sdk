Validación Anti-Cheat autoritativa de movimientos en el servidor Relay para chess y checkers.

Cuando una sala se crea con "game_id": "chess" o "game_id": "checkers", el Relay mantiene una instancia local de open_table_engine::session::Session y verifica cada movimiento antes de retransmitirlo a los demás participantes.
