Validación Anti-Cheat autoritativa de movimientos en el servidor Relay para los 14 juegos del catálogo.

Cuando una sala se crea con cualquiera de los 14 identificadores canónicos ("chess", "checkers", "go", "shogi", "xiangqi", "backgammon", "battleship", "ludo", "mille_bornes", "monopoly", "uno", "crisis", "chinese_checkers", "goose"), el Relay mantiene una instancia autoritativa de open_table_engine::session::Session inicializada con una semilla determinista (seed) y verifica cada jugada antes de retransmitirla.
