Module auth 

Source
Expand description

Validación y emisión de tokens JWT (HS256) para el servidor Relay.

Lee JWT_SECRET desde las variables de entorno:

  • Si no está presente, la autenticación queda desactivada (modo desarrollo local).
  • Si está presente, el cliente debe enviar {"op": "auth", "token": "<jwt>"} en los primeros 5 segundos tras conectar.
  • Valida estrictamente la firma HMAC-SHA256 y el campo exp. Tokens expirados son rechazados con {"op": "auth_error", "reason": "expired"}.
