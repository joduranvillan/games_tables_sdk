pub fn checkers_ai_pick_move(
    session: &Session,
    player: PlayerId,
) -> Option<MovePieceCommand>
Expand description

Selecciona una jugada legal para el jugador especificado en la sesión dada.

Si existen capturas legales, selecciona una al azar entre ellas. Si no hay capturas, selecciona al azar entre los movimientos simples legales. Devuelve None si la partida ha terminado, si no es el turno del jugador o si no hay movimientos legales disponibles.
