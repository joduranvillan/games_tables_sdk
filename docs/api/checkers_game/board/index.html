Quién avanza en qué dirección. increasing empieza arriba (filas 0-2) y se mueve hacia filas más altas; decreasing empieza abajo (filas 5-7) y se mueve hacia filas más bajas. Se decide una sola vez al armar el tablero inicial y no cambia en toda la partida.
