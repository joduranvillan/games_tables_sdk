Juego de referencia del OpenTable SDK: damas.

Ejercita el SDK completo: Command/Event via los derives de open_table_macros, dos Resource (BoardResource, Sides), turnos (TurnResource del engine), y una condición de victoria. Sin información oculta (a propósito: damas es el caso más simple posible antes de meterse con un juego de cartas).

Para jugarlo de punta a punta sin esperar a open_table_godot, ver examples/local_match.rs (dos jugadores por consola, mismo proceso).
