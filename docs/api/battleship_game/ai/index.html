Inteligencia Artificial para Batalla Naval (Battleship) con Probabilistic Targeting.

Niveles de dificultad (AiDifficulty):

  • Easy: disparo pseudoaleatorio en celdas no disparadas.
  • Medium: modo Hunt/Target — disparo aleatorio en celdas no disparadas, pero prioriza celdas ortogonalmente adyacentes si existe algún impacto sin hundir.
  • Hard / Expert: mapa de densidad de probabilidad (probability density map) — cuenta cuántas orientaciones válidas de barcos aún no hundidos pueden cubrir cada celda no disparada (ponderando fuertemente las alineaciones que cubren impactos activos sin hundir) y dispara a la celda de mayor densidad.
