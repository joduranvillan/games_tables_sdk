pub fn compute_probability_density_map(
    state: &BattleshipState,
    ai_player: PlayerId,
) -> [[u32; 10]; 10]
Expand description

Calcula el mapa de densidad de probabilidad (10x10) para ai_player: Para cada tamaño de barco aún no hundido, cuenta cuántas ubicaciones horizontales y verticales válidas cubren cada celda no disparada. Si una ubicación válida pasa además por uno o más impactos sin hundir (unsunk_hits), recibe una ponderación adicional proporcional para priorizar el hundimiento del barco detectado.
