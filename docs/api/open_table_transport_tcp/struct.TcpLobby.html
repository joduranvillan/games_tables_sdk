Expand description

Sala de espera (lobby) previa al inicio de una partida sobre TCP.

Escucha conexiones entrantes, recolecta las identidades de los jugadores que se van uniendo (JoinedPlayer), y permite transicionar la sala hacia un TcpHostTransport completo listo para jugar mediante start_game().
