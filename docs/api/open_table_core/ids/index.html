IDs fundamentales. Todos son newtypes sobre enteros: sin punteros, sin referencias, para que cualquier Command/Event que los contenga sea trivialmente serializable y determinista entre plataformas.

Structs§

EntityId
Identifica una entidad dentro del ECS (jugador, propiedad, carta, ficha…). Definido acá y no en el motor para que los Command/Event puedan referenciar entidades sin depender del crate de ECS.
PlayerId
Identifica a un jugador dentro de una Session. Asignado por el host al aceptar la conexión, nunca por el propio cliente.
SessionId
Identifica una partida/sala completa.
SpectatorId
Identifica a un espectador dentro de una Session.
Tick
Tick lógico de simulación. Nunca tiempo de reloj real (ver time.rs).
