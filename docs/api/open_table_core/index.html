§open_table_core

Core traits and types for deterministic turn-based board game engines.

§Examples

use open_table_core::prelude::*;

let p1 = PlayerId(1);
let p2 = PlayerId(2);
let diff = AiDifficulty::from_i64(2);
assert_eq!(diff, AiDifficulty::Hard);
assert_eq!(diff.max_depth(), 3);
assert!(diff.use_opening_book());

let result = GameResult {
    winner: Some(p1),
    duration_ms: 15_000,
    total_moves: 42,
    players: vec![p1, p2],
    game_name: "chess".to_string(),
};
assert_eq!(result.winner, Some(PlayerId(1)));

§open_table_core

Tipos y contratos fundacionales de OpenTable Engine.

Este crate no conoce ECS (bevy_ecs), red real (sockets, Nearby Connections), ni Godot. Define el vocabulario común (IDs, Command/Event como trait objects serializables, Component/Resource, RandomService determinista, GameClock, trait Transport) compartidos por todos los juegos de mesa y capas superiores del SDK.
