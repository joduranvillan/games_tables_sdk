Libro de aperturas ECO compacto (A00-E99) indexado por hash Zobrist de 64 bits.

En los niveles AiDifficulty::Hard y AiDifficulty::Expert, la IA consulta OpeningBook::lookup(zobrist_hash) para responder instantáneamente con aperturas teóricas ponderadas por frecuencia de uso.
