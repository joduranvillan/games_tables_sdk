Inteligencia Artificial MCTS ligero para Damas Chinas (Chinese Checkers).

  • Ejecuta difficulty.rollouts() simulaciones aleatorias (playouts).
  • Función de evaluación: distancia total hexagonal de los peones del jugador al objetivo (minimizar suma de distancias al vértice objetivo).
