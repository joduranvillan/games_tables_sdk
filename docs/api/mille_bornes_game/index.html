Mil Millas (Mille Bornes): juego de cartas de referencia. Maneja manos privadas, descarte de cartas, restricción por límite de velocidad (máximo 50 km), rebarajado de la pila de descarte al vaciarse el mazo, peligros, remedios y avance hasta la meta.
