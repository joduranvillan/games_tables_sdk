Backgammon: juego de referencia para 2 jugadores. Soporta tiradas con dobles (4 movimientos iguales), punto de entrada desde la barra, regla de bear-off (sacar fichas) y paso automático de turno cuando no hay movimientos válidos con los dados tirados.
