Inteligencia Artificial con Monte Carlo Tree Search (MCTS) y heurísticas tácticas para Crisis / TEG.

Cubre las tres fases principales del turno:

  • Colocación (PlaceArmies): refuerza el territorio propio más amenazado (menor ratio ejércitos_propios / ejércitos_vecinos_enemigos).
  • Ataque (Attack): ataca si ejércitos_atacantes > ejércitos_defensores * umbral (Easy: 2.0, Medium/Hard: 1.5, Expert: 1.2), evaluando con rollouts MCTS la probabilidad de conquista. En Expert, prioriza objetivos que acercan al ObjectiveCard secreto.
  • Fortificación (Fortify): mueve ejércitos excedentes al territorio fronterizo más débil conectado.
